プライバシーポリシー / Privacy Policy

巨大数への旅（Googology Trip）は、アプリ内でユーザーデータを収集しません。

Googology Trip does not collect user data within the app.

  • 保存されるデータは、ゲーム内の進捗状況のみです。
  • 保存されたデータは、セーブデータを維持するために使用されます。
  • データは端末内にのみ保存され、第三者に共有されません。
  • アプリを削除すると、保存されたデータは端末から削除されます。

  • Only game progress data is stored.
  • The stored data is used only to maintain save data.
  • The data is stored only on the user’s device and is not shared with any third party.
  • If the app is deleted, the stored data is also removed from the device.
